# Resume Optimizer Service

## What It Does
Analyzes resumes for ATS compatibility, optimizes content, and generates LinkedIn profiles.

## API Endpoints
- `POST /analyze` — Upload resume for analysis
- `GET /analyses/{id}` — Get analysis results
- `POST /analyses/{id}/optimize` — Generate optimized version
- `POST /linkedin` — Optimize LinkedIn profile
- `GET /health` — Health check
